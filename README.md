# Salvacion Mata Domingo

A responsive academic portfolio for GitHub Pages featuring research, publications, and student mentoring. Open `index.html` locally in a browser to preview it.

## Update the portfolio

Edit `index.html` to update the biography, publications, research projects, teaching, or profile links. Link new publications to their DOI or publisher page.

## Publish

Push these files to the default branch of your GitHub repository. In the repository's **Settings → Pages**, select **Deploy from a branch**, choose the default branch and **/(root)**, then save. GitHub displays the published URL on that page once deployment succeeds.

[GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
